## Wi-Fi credential safety update

- New or changed Wi-Fi credentials are saved only after a successful connection.
- A failed password no longer overwrites a previously saved password for the same SSID.
- After a failed connection attempt, the SOUND-TERRARIUM-SETUP access point starts again for another attempt.
- The setup page includes FORGET ALL to clear saved Wi-Fi networks when required.

## Setup portal UI refinements

- The Wi-Fi setup home page no longer gets stuck showing an outdated version from the browser's cache after a firmware update.
- The "Testing..." page now explicitly tells the user to check the Cardputer's own screen for the actual connection result, since the page itself never updates.
- The Password field now starts on its own line instead of appearing next to the network dropdown.
- The "Wi-Fi cleared" confirmation page now renders at proper phone-screen scale (previously showed with tiny text) and automatically returns to the setup page after 1 second.

The sound-generated terrain, runner, weather, temperature colors, controls, and other visual behavior are unchanged from v108br.
